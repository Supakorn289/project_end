7. True North

ใช้ CamFinder เรียก P1 แล้ววัดทิศจริงของจุดกลางภาพ ด้วยเข็มทิศหรือแผนที่ จากนั้นกรอกค่า 0–360°

8. ตำแหน่งกล้อง GPS

กรอกพิกัดจริงของตำแหน่งที่ติดตั้งกล้อง ขั้นนี้ยังไม่เปิด GPS Output จนกว่าจะ Activate Site

ยังไม่ได้ตั้งตำแหน่งกล้อง

9. Telegram Notification

กรอก Bot Token และ Chat ID สำหรับรับข้อความแจ้งเตือนไฟ/ควัน Token จะถูกเก็บเป็น Candidate และจะไม่แสดงกลับบนหน้าเว็บ

Bot Token ได้จาก BotFather ส่วน Chat ID คือห้องส่วนตัว/กลุ่ม ที่ต้องการรับการแจ้งเตือน

ยังไม่ได้ตั้งค่า Telegram
