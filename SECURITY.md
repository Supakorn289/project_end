# Security Policy

## Sensitive Information

Do **not** submit or commit:

- camera credentials
- Telegram tokens or chat IDs
- manager login tokens
- production `.env`
- precise private-site coordinates
- private RTSP URLs
- site-specific calibration state
- camera captures from private installations

## Vulnerability Reporting

Do not open a public issue containing credentials, private addresses, tokens, or exploit details that could expose an installed system.

Use a private contact method provided by the repository owner.

## Privileged Components

The Manager Root Agent is privileged software. Changes to privileged actions must remain narrowly scoped. Do not add arbitrary shell execution.
