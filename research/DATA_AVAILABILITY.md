# Data Availability

## Public Repository

The public repository should contain source code, deployment scripts, documentation, tests, and only sanitized example media.

## Not Public by Default

Do not publish:

- private-site camera footage
- raw RTSP captures
- credentials
- precise private-site coordinates
- manager tokens
- production environment files
- site-specific runtime revisions
- data without verified redistribution rights

## Model Weights

Redistribute model weights only if the project owner has verified the applicable license and dataset/model redistribution rights.

## Research Release

If a dataset or evaluation sample can be published, release it separately with:
- source/provenance
- license
- consent/privacy review where applicable
- train/validation/test split definition
- checksum
